# Информационная система «Агентство недвижимости»

## Стек технологий
* **Язык программирования:** Python 3.14+
* **Тестирование:** `pytest`
* **Хранение данных:** JSON

## Целевая аудитория
* **Риелторы** — ведение карточек объектов и клиентов, подбор вариантов, фиксация этапов сделок.
* **Менеджеры ** — мониторинга статуса текущих сделок и формирования отчётов.
* **Администраторы** — настройка справочников и контроль прав доступа.

## Основные функции
1. **Управление объектами недвижимости:** добавление, редактирование, изменение статуса и удаление объектов.
2. **Ведение клиентской базы:** учет продавцов, покупателей и арендаторов с их требованиями и бюджетом.
3. **Многокритериальный поиск:** фильтрация объектов по цене, площади, количеству комнат и типу сделки.
4. **Автоматический подбор:** поиск релевантных объектов под активные заявки клиентов.
5. **Сопровождение сделок:** фиксация связки «Объект — Клиент — Агент» и отслеживание статусов сделки.
6. **Аналитика и отчеты:** расчет количества закрытых сделок и суммы комиссионных за период.

## Структура проекта
* `src/` — исходный код основного модуля (модели, бизнес-логика, интерфейс).
* `docs/` — техническая документация и описание предметной области.
* `config/` — конфигурационные файлы и настройки окружения.
* `scripts/` — вспомогательные скрипты (инициализация БД, генерация тестовых данных).
* `lib/` — внешние или переиспользуемые вспомогательные библиотеки и валидаторы.
* `test/` — модульные и интеграционные тесты.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/username/project
   cd project
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3.14 -m venv .venv
   # Для Linux/macOS:
   source .venv/bin/activate
   # Для Windows:
   .venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   python -m src.cli
   ```

5. **Запустите тесты:**
   ```bash
   python -m pytest -v
   ```
